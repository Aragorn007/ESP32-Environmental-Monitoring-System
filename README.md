# ESP32-Environmental-Monitoring-System

A custom 2-layer PCB designed in KiCad for IoT sensing and monitoring applications.

## Features

- ESP32-WROOM-32 MCU
- 24V to 3.3V Buck Conversion
- UART Interface
- I2C Expansion Header
- LDR Sensor Interface
- Push Button Controls
- Ground Plane Design
- RF Antenna Keep-Out Region

## Tools Used

- KiCad 10
- ESP32-WROOM-32
- LM2596 Buck Converter

## Design Highlights

- Two-layer PCB
- Dedicated ground plane
- RF antenna isolation region
- DRC/ERC verified
- Manufacturing-ready Gerber files
